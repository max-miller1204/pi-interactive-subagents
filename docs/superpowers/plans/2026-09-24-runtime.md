# Subagent Runtime Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Pi parent and child runtime in HANDOFF.md section 10, step 3.

**Architecture:** A factory owns one active runtime per Pi session. The parent role supervises child runs and delivers outbox items. The child role reads its inbox, handles questions, and exits when its work is settled. Both roles share one delivery state machine and the foundation's strict disk schemas, session reader, catalog, launcher, queue, and tmux adapter.

**Tech Stack:** Node 24, TypeScript with strict NodeNext, Pi 0.87.1, TypeBox 1.3.27, pi-ai faux provider, Node test runner, tmux 3.3 or newer.

### Task 1: Durable boundary delivery

**Files:** Create `src/delivery.ts`, `test/unit/delivery.test.ts`. Modify `test/sdk/harness.ts` only to expose controlled boundary events and a writable session path.

**Interfaces:** Consumes `src/queue.ts` and `src/session-file.ts` delivery ids. Produces `Deliverer`, `Source`, `Item`, `Outgoing`, `RegistryDraft`. A source has `items(): Item[]`, `build(item): Outgoing | "drop"`, optional `prelude(item): RegistryDraft[]`, and `confirm(item): void`. The constructor receives `pi`, `ctx`, `sources`, `isDisposed` and a child task-gate flag. Public methods are `pump()`, `onInput()`, `onAgentStart()`, `onBoundary(event)`, `onAgentSettled()`, `reconcile()`, and `shutdown()`.

**Contract sketch:** Keep the source API small and use durable confirmation.

```ts
type Item = { id: string };
type RegistryDraft = { customType: "subagent"; data: RegistryRecord };
interface Source {
  key: string;
  items(): Item[];
  build(item: Item): Outgoing | "drop";
  prelude?(item: Item): RegistryDraft[];
  confirm(item: Item): void;
}
function confirmed(id: string, ctx: ExtensionContext): boolean {
  const file = ctx.sessionManager.getSessionFile();
  return file !== undefined && existsSync(file) &&
    ctx.sessionManager.getEntries().some(entry =>
      entry.type === "custom_message" && entry.details?.deliveryId === id ||
      entry.type === "message" && entry.message.role === "toolResult" &&
      entry.message.details?.deliveryId === id);
}
```

**Contract sketch:** One close transition removes the question file and abort listener.

```ts
type WaiterState = "open" | "answered" | "withdrawn" | "disposed";
function close(waiter: Waiter, next: Exclude<WaiterState, "open">): void {
  if (waiter.state !== "open") throw new Error(`Question ${waiter.qid} is already ${waiter.state}.`);
  waiter.state = next;
  waiter.signal?.removeEventListener("abort", waiter.onAbort);
  waiters.delete(waiter.qid);
  unlinkSync(join(runDir, "questions", `${waiter.qid}.json`));
  writeStatus();
}
```

**Contract sketch:** Route Pi events to the current per-session runtime.

```ts
export function createSubagentsExtension(pi: ExtensionAPI, deps: RuntimeDeps): void {
  const [major, minor] = VERSION.split(".").map(Number);
  if (major !== 0 || minor !== 87)
    throw new Error(`pi-interactive-subagents 4 needs Pi 0.87. This Pi is ${VERSION}. Install Pi 0.87, or update pi-interactive-subagents.`);
  pi.registerFlag("subagent-run", { description: "Run directory for a subagent", type: "string" });
  let runtime: Runtime | undefined;
  pi.on("session_start", async (event, ctx) => { runtime = await startRuntime(pi, ctx, deps, event); });
  pi.on("session_shutdown", async (event) => { await runtime?.onShutdown(event.reason); runtime = undefined; });
}
```
